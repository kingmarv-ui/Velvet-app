# Velvetmoon Spa

Luxury appointment booking for Velvetmoon Spa — treatments, calendar, client details, deposit, and confirmation.

## What’s included

- Mobile-first spa home page (about, policies, contact, hours, services)
- Multi-service booking in 3 steps: services → schedule & details → review & pay
- Demo card and bank-transfer checkout (nothing is charged)
- Instant confirmation with a booking reference

Edit services, prices, hours, contact, and policies in `src/lib/spa-config.ts`.

## Run locally

```bash
npm install
npm run dev
```

Then open the app in your browser. `npm run build` creates a production build.
